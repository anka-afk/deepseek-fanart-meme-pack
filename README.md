# DeepSeek 二创表情包

Meme Manager 官方维护适配包，收录不同画风的 DeepSeek 二创素材，可与其他 DeepSeek 表情包并存。

## 安装

在 Meme Manager 资源广场的官方包区域安装「DeepSeek 二创表情包」。

仓库：https://github.com/anka-afk/deepseek-fanart-meme-pack

发布版本：v1.0.0。适配与维护：anka-afk。

- 174 张素材：98 PNG、45 WebP、27 JPEG、4 GIF。
- 4 个 GIF 保留原始动画；其他图片均为静态图。
- 原图按字节复制，没有重新编码；仅将一个内容实际为 PNG 的 .jpg 文件改用正确扩展名。
- manifest.json：包信息和分类；memes_data.json：兼容分类说明。
- source_index.json：原文件映射、格式、尺寸、帧数和 SHA-256。
- previews/：封面及五张全量总览，总览编号对应整理后文件名前缀。

## 分类

- sleep：8 张。用于睡觉、休息、犯困、结束工作、躺平或表示暂时离线。
- money：4 张。用于 token、算力、打折、收费、预算或其他资源消耗话题。
- food：15 张。用于吃饭、喝汤、投喂、购物、馋嘴、做饭或拿食物开玩笑。
- affection：7 张。用于表达喜欢、贴贴、感谢、爱心互动或友好亲近。
- angry：17 张。用于生气、抗议、拒绝、催促、责备或夸张式威胁；避免用于真实冲突。
- sad：23 张。用于哭泣、委屈、受挫、疲惫、没钱、被打击或自嘲性低落。
- confused：24 张。用于疑问、没听懂、反问、选择困难、知识截止时间或模型识别困惑。
- happy：20 张。用于开心、胜利、鼓掌、夸赞、上线、打招呼或积极回应。
- work：18 张。用于训练、推理、加班、写代码、测试、记录、客服、工作区和任务处理。
- greeting：10 张。用于自我介绍、宣布到达、身份说明、向用户回应或展示 DeepSeek 形象。
- tech：13 张。用于模型、开源、版本更新、蒸馏、服务器、部署、API 和技术讨论。
- portrait：11 张。用于角色立绘、服装展示、动态实拍或作为非文字化形象回应。
- teasing：4 张。用于玩梗、整活、调侃竞争模型或轻松吐槽；不用于恶意攻击。
